# Modelling
Filene i denne mappen tar for seg klasser som analyserer, visualiserer og predikterer dataen. 

##### data_analysis.py:
Data_analysis.py lager klassen som blir brukt i data_analysis.ipynb i notebooks-mappen. Filen har værklasser for nedbør og vind fra:
Meteorologisk institutt. (2017, Mars 21). Begreper i værvarsling. Hentet fra Meteorologisk institutt: https://www.met.no/vaer-og-klima/begreper-i-vaervarsling

MERK: Nedbør er for de siste 24 timene, men styrtregn er bare for en time. Vind er i m/s

##### data_visual.py:
data_visual.py lager klassen som blir brukt i data_visual.ipynb i notebooks-mappen.

##### missing_values.py:
missing_values.py lager klassen som blir brukt i predictive_analysis.ipynb i notebooks-mappen.

##### predictive_analysis:
predictive_analysis lager klassen som blir brukt i predictive_analysis.ipynb i notebooks-mappen.
