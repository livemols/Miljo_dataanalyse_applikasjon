# Testing
I denne mappen ligger det unittester for det som var dømt nødvendig, blant annet funksjoner og logiske metoder. Dette var en arbeidsmetode for oss for å kvalitetsikre koden vår, spesielt hardkodingen. 

##### test_data_analysis.py:
 Denne filen lager unittest for metoder og funksjoner innenfor data_analysis.py i mappen src/modelling.

##### test_data_cleaning.py:
 Denne filen lager unittest for metoder og funksjoner innenfor data_cleaning.py i mappen src/data_preparation.

##### test_predictive_analysis.py:
 Denne filen lager unittest for metoder og funksjoner innenfor predictive_analysis.py i mappen src/modelling
